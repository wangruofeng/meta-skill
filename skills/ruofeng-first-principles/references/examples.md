## 示例 2：商业模型（公司分析）

输入：「帮我用第一性原理分析 Shein 为什么能这么快」

输出骨架：

```
# Shein 商业模式的第一性原理拆解

## 核心洞察
Shein 不是在卖衣服，是在解决「时尚供应链的信息不对称」——需求信号到成衣的最小延迟。

## 根本问题
| 根本问题 | 通俗说法 | Shein 的答案 |
| 怎么知道用户要什么 | 需求信号 | 实时数据抓取 + 小单快反 |
| 怎么快速做出来 | 供应链速度 | 柔性供应链 + 100 件起订 |
| 怎么让用户看到 | 流量获取 | 社交媒体矩阵 + 低价引流 |
| 怎么定价能赚钱 | 定价模型 | 极致低价 + 规模效应 |

## 心智模型
快时尚的本质不是「快」，是「信息损耗最小化」——从需求信号到货架的时间越短，库存风险越低。
```

## 示例 3：论证文章

输入：「帮我用第一性原理拆解 Paul Graham 的《Do Things That Don't Scale》」

输出骨架：

```
# Do Things That Don't Scale 的第一性原理拆解

## 核心洞察
文章回答一个问题：初创公司早期，什么是「正确」的增长方式？

## 根本问题
| 根本问题 | 通俗说法 | 文章的答案 |
| 早期增长的本质是什么 | 增长到底是什么 | 找用户，不是等用户来 |
| 为什么不能等产品完美 | 完美主义陷阱 | 用户反馈才是最好的产品经理 |
| 手动操作为什么有效 | 不规模化 | 手动让你理解用户，规模化只是加速器 |
| 什么时候可以停止 | 拐点判断 | 当你对用户问题已形成直觉、手动不再带来新信息时 |

## 心智模型
初创早期 = 信息收集阶段，不是执行阶段。「不规模化」是最高效的信息收集方式。
```
